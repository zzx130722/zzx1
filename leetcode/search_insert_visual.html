4三个新手大坑

    
二分查找的循环只有 6 行，难点从来不在思路，而在这三个边界上。

    

      

        
坑 1：while left <= right

        
左闭右开区间下，left == right 表示空区间，不该再进循环。

        
写成 <= 会算出 mid == len(nums)，然后 nums[mid] 直接越界报错。

        
记法：区间开闭和循环条件要一致。

      

      

        
坑 2：right = mid - 1

        
nums[mid] >= target 时，mid 本身可能就是答案（target 正好等于它）。

        
mid - 1 等于亲手把正确答案扔了 —— 上面选 target = 5 走一遍再对照代码就能看出它会返回 1，是错的。

        
记法：一边加一、一边不加，不对称才对。

      

      

        
坑 3：忘了「插到末尾」

        
target 比所有数都大时，答案是 len(nums)。

        
若用左闭右闭写法从 right = len(nums) - 1 起步，最大值只到 3，必须额外补一个分支 —— 特别容易漏。

        
记法：右端点从 len(nums) 起步。

      

    


    
正确的写法长这样，就 6 行：

    
def search_insert(nums, target):
    left, right = 0, len(nums)        # 左闭右开区间 [0, len)
    while left < right:               # 区间里还有元素就继续
        mid = (left + right) // 2     # 取中点（下取整）
        if nums[mid] < target:        # 中间值太小
            left = mid + 1            #   答案在右半边，mid 排除
        else:                         # 中间值够大（>=）
            right = mid               #   答案在左半边，mid 保留！
    return left                       # 区间空了，left 就是答案
