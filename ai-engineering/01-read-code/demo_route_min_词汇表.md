# 词汇表：demo_route_min.py 每个英文单词的中文意思

> 配合 `demo_route_min.py` 使用。读代码时哪个词不认识，来这里查。
> 已按"出现的先后顺序"排列。

---

## 一、符号和语法（不是单词，但必须认识）

| 符号 | 读法 | 意思 |
|---|---|---|
| `def` | —— | **define 的缩写，"定义"**。后面跟函数名，意思是"我要定义一个函数了" |
| `()` | 小括号 | 两种用途：① 定义函数时放参数；② 调用函数（"执行它"）就加在函数名后面 |
| `"""..."""` | 三引号 | 长注释，一般放在文件开头或函数开头，说明"这是干嘛的" |
| `#` | 井号 | 单行注释，`#` 后面的话是写给人看的，电脑不执行 |
| `@` | at，读"艾特" | **装饰器符号**。意思是：把我下面的函数，交给 `@` 右边的东西去处理 |
| `:` | 冒号 | "下面开始是我管的内容"，代码块从这里开始（配合缩进） |
| `->` | 箭头 | "返回的是什么"，写在函数定义末尾，是给人看的说明 |
| `f"..."` | f 字符串 | f = **format（格式化）**。字符串里可以用 `{}` 塞变量，如 `f"你好 {名字}"` |
| `{}` | 大括号 | 在 f 字符串里表示"这里填变量的值" |
| `{}`（单独用） | 大括号 | 也表示**字典**：一种"登记本"，左边是钥匙（键）、右边是内容（值） |
| `["..."]` | 方括号 | 取字典里的东西：`登记本["/home"]` = 查"/home"登记的内容 |
| `==` | 两个等号 | "等于吗？"（用来比较）；**一个等号 `=` 是"把右边的存进左边"** |
| `.` | 点 | "的"。`func.__name__` = func 的 __name__；`路径/a.py` = 路径下的 a.py |
| `*` | 星号 | 乘号；此处代码里没用到别的含义 |
| `'` 或 `"` | 引号 | 字符串（一段文字）的边界。引号包起来的就是文字，不是代码 |

## 二、代码里出现的英文单词（按出现顺序）

| 单词 | 本意 | 在这份代码里的意思 |
|---|---|---|
| `route` | 路线 | **路由**：一个网址对应哪个函数的"路线规则"。Flask 最核心的词 |
| `url` | Uniform Resource Locator 的缩写 | **网址**，比如 `/home` |
| `table` | 桌子、表格 | 这里指**登记表**：`route_table` = 路由登记表（网址→函数 的对照表） |
| `print` | 打印 | **往屏幕上输出一行字**，调试时最好用的工具 |
| `decorator` | 装饰者 | **装饰器**：接收一个函数、再做点额外事情的函数（这里就是"登记员"） |
| `func` | function 的缩写 | **函数**。这里特指"被登记的那个函数"（比如 hello） |
| `__name__` | name = 名字（前后各两条下划线） | 函数的**名字**。`func.__name__` = 这个函数叫什么（不写括号是"问名字"，加了括号才是"执行"） |
| `return` | 返回 | **交还结果**。函数执行完，把某个东西交还给调用它的人；也代表"函数到此结束" |
| `hello` | 你好 | 示例函数名，随便起的（就像给宠物起名） |
| `home` | 家 | 示例网址 `/home`，表示"主页"，也是随便起的 |

### 特别强调三组最容易混的

**① `hello` 和 `hello()`（差一个括号，天壤之别）**
- `hello` → 函数**本身**（像"厨师本人"，可以递给登记员）
- `hello()` → **执行**这个函数（厨师真的开始做饭了），括号就是"开工"的意思

**② `route` 和 `route()`**
- `route` → 这个函数本身
- `route("/home")` → 执行它，并且把 `"/home"` 作为信息交给它

**③ `=` 和 `==`**
- `route_table[url] = func` → **存进去**（登记）
- `a == b` → 问一句"a 和 b 相等吗"，得到"是/否"

## 三、Flask 真源码里的 6 个词（进阶，可跳过）

| 单词 | 本意 | 意思 |
|---|---|---|
| `self` | 自己 | "我自己"这个对象。类的方法第一个参数永远是 self，代表"当前这个 app" |
| `rule` | 规则 | Flask 里把"网址规则"叫 rule，`route` 的第一个参数就存进 Rule 对象 |
| `options` | 选项 | 额外参数打包在一起的字典。`**options` 表示"把字典里的东西一个个展开传过去" |
| `endpoint` | 端点 | 函数的**别名/编号**。Flask 内部靠它找到函数，默认就用函数名 |
| `add_url_rule` | 添加网址规则 | 三个词连读：add（添加）+ url（网址）+ rule（规则）= **"往登记表里加一条"** |
| `Callable` | 可被调用的 | 类型标注用词：表示"这是一个能加括号执行的东西"（通常是函数） |

## 四、一句话复习

> `@route("/home")` = 先把网址 `/home` 交给 route → route 造出一个登记员 decorator → 登记员拿到下面的函数 hello → 在登记本上写下"**/home 找 hello**" → 把 hello 原样还给你。
